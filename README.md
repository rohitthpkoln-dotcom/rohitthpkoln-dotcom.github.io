# rohitthpkoln-dotcom.github.io

Personal website of Rohit Mukherjee, served by GitHub Pages from the `main` branch.

## How it works

Every page is plain HTML generated by one script from the JSON files in `content/`:

| Page | Edit this file |
|---|---|
| Home (bio, photo, icon links) | `content/site.json` |
| Research Interests | `content/research.json` |
| Publications | `content/publications.json` |
| Talks | `content/talks.json` |
| Teaching | `content/teaching.json` |
| Conferences & Workshops | `content/conferences.json` |
| Notes | `posts/<slug>/content.md` (Markdown + LaTeX) |

After editing, rebuild and commit:

```bash
python3 scripts/build_site.py
```

Preview locally from the repository root:

```bash
python3 -m http.server 8000      # then open http://localhost:8000
```

Colours, fonts and spacing are CSS variables at the top of `assets/site.css`.

## Entry formats

Text fields may contain simple HTML (`<i>`, `<b>`, `<a href="...">`).

**Publication** (inside `sections[].entries` of `publications.json`):

```json
{"title": "Paper title", "authors": "With A. Author and B. Author.", "date": "March 2026.",
 "status": "Submitted.", "journal": "Phys. Rev. B 111, 012345 (2026)", "doi": "10.1103/...",
 "arxiv": "2603.01234", "category": "cond-mat.str-el", "links": [{"label": "Code", "href": "https://..."}]}
```

`in_preparation` takes `{"title": "...", "with": "A. Author"}`.

**Talk** (`talks.json`, grouped by year automatically):

```json
{"title": "Talk title", "sort": "2026-07", "date_text": "July 2026", "event": "Workshop name",
 "event_url": "https://...", "place": "Cologne", "links": [{"label": "Slides", "href": "/assets/slides.pdf"}]}
```

**Teaching** (`teaching.json`):

```json
{"name": "University of Cologne", "text": "Optional paragraph.",
 "terms": [{"term": "Winter Term 2025/26", "courses": [{"title": "Course", "role": "Teaching assistant"}]}]}
```

**Conference** (`conferences.json`, lists `upcoming` and `past`):

```json
{"title": "Conference name", "url": "https://...", "date": "June 2026", "place": "Trieste", "role": "Speaker"}
```

## Photos

Put images in `assets/img/` and set `"photo"` (home portrait) or a page key under
`"banners"` in `content/site.json`, e.g. `"talks": "/assets/img/talks.jpg"`. Pages without a
banner photo use a coloured gradient.

## New note

```bash
python3 scripts/new_post.py "My New Note"
```

This creates `posts/my-new-note/content.md`; write the note there (math with `\(...\)` and
`\[...\]`), then rerun `scripts/build_site.py`. Notes are rendered in the browser with
`marked` and MathJax.
